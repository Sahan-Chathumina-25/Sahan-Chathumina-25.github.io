# Sahan Chathumina — Portfolio

A dark, futuristic portfolio for a Network Engineering & Cybersecurity profile.

## Run locally

```bash
npm install
npm run dev
```

Open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
npm run preview
```

## Personalise

Edit `src/main.jsx`:
- `profile` for GitHub, LinkedIn and email
- `projects` for your real projects
- `skills` for your exact skill set
- `architecture` for your actual topology
- education/certification text in the Education section

Replace placeholder social links and email before deploying.
